Amobi Damage (AmobiDamage.ttf)

The damage-number font used by Amobi Companion (阿莫比小幫手). It is a modified
version made by wowamobi.com from two fonts under the SIL Open Font License 1.1:

  * Bangers - Copyright 2010 The Bangers Project Authors
    (https://github.com/googlefonts/bangers). Used for digits and Latin letters,
    scaled up 1.2x. License: OFL-Bangers.txt
  * Noto Sans TC (Black weight) - Copyright 2014-2021 Adobe
    (http://www.adobe.com/), with Reserved Font Name 'Source'.
    Used for the Chinese characters (Big5 plus the game's UI strings).
    License: OFL-NotoSansTC.txt

The merged font is renamed "Amobi Damage" and is released under the same
SIL Open Font License 1.1. It must not be sold by itself.

字型說明：「阿莫比爽字」是把 Bangers 的數字、英文和思源黑體（Noto Sans TC）最粗的中文合成的字型，
兩個都是 SIL Open Font License 1.1 授權，合成後的字型也照這個授權發布，授權全文在同一個資料夾。
